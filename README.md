# 🌙 LunaOS

**An Ubuntu-based Linux distribution for everyday computing.**

LunaOS is an independent Linux distribution project built on top of Ubuntu, focusing on accessibility, customization, usability, and a clean desktop experience.

## Project Information

| Property | Details |
|---|---|
| Name | LunaOS |
| Version | 0.1.0 Alpha |
| Base Distribution | Xubuntu 24.04 LTS |
| Desktop Environment | XFCE |
| Architecture | AMD64 |
| Package Manager | APT |
| Project Status | Early Development |

## Project Goals

- Provide a comfortable everyday computing experience.
- Deliver a customizable XFCE desktop environment.
- Maintain a stable and maintainable Ubuntu foundation.
- Develop a distinct LunaOS identity.
- Gradually introduce additional security and system management features.
